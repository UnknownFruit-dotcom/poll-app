# PollApp — Приложение для голосований и опросов

веб-приложение для создания опросов и голосований.

## О проекте

Мы разрабатываем современный сервис, где пользователи могут:
- Создавать опросы с разными типами вопросов
- Делиться ссылками на голосование
- Просматривать результаты в реальном времени
- ...

## Технологический стек

**Frontend:**
- TypeScript(React)

**Backend:**
- PHP(Laravel)

**База данных:**
- PostgreSQL
- Docker Compose
